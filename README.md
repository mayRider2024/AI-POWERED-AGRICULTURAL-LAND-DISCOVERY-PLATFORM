# AI-POWERED AGRICULTURAL LAND DISCOVERY PLATFORM (LandLens AI)

An AI-powered agricultural land discovery application for Raigad, Palghar, and Panvel (Maharashtra).

## Core Architecture
- **Frontend**: React, Vite, TypeScript, Tailwind CSS
- **Mobile / Android**: Capacitor
- **Maps & Spatial**: MapLibre GL with OpenFreeMap and OpenStreetMap data
- **Backend**: FastAPI, Python, SQLAlchemy, Alembic, PostgreSQL
- **AI Engine**: Gemini via secure FastAPI proxy

## Features
- Voice & natural-language search (English, Marathi, Hindi)
- Land Records integration & 7/12 document assistant
- Real road proximity & MapLibre layers
- Broker & seller property submission workflow with verified landowner consent
- Land intelligence reports & property comparison
- Responsive Android layout with bottom navigation and offline demo fallback
